# Exclusive occupancy of p65 Cys38 under thermodynamic constraint

Reference implementation for the manuscript *Thermodynamically Constrained
Exclusive Occupancy of p65 Cysteine 38 Resolves the Persulfidation–Overoxidation
Competition in Neuronal Oxygen–Glucose Deprivation*.

The code implements a four-layer kinetic model in which the chemical state of a
single cysteine is carried as a point on a probability simplex. The six vertices
are the thiolate, sulfenic acid, persulfide, sulfinate, glutathionylated and
nitrosylated forms of Cys38 on the NF-κB p65 subunit. Because these are
alternative fates of one sulfur atom, occupancy is categorical rather than
combinatorial, which is what distinguishes the formalism from multisite
modification theory.

Rate constants are not free parameters. Each state carries a free energy and
each edge a barrier and a cosubstrate free-energy change, so every closed cycle
of the reaction graph has an affinity that depends on chemical potentials alone.
This enforces the Wegscheider conditions by construction and is verified
numerically to machine precision by `tessera_calibrate.equilibrium_check`.

## Status of the results

**Everything produced here is computational.** No experimental measurement is
involved at any point. Observation sets are generated by the calibrated model
and corrupted with assay-appropriate error, so the analyses test recoverability,
identifiability and structural capability — not agreement with data. Rate
constants for the competing reactions at p65 Cys38 have never been measured;
`tessera_params.PROVENANCE` records, for every parameter, whether its value is
taken from published measurement, from a published range, or estimated.

## Install

```
python -m pip install -r requirements.txt
```

Python 3.10 or newer. No compiled extensions and no GPU.

## Reproduce

```
python run_all.py          # the main sequence of experiments
python run_followups.py    # analyses that depend on the fits
python tessera_figures.py  # all figures, written to ./figures
```

`run_all.py` writes `results.json` incrementally and skips any stage already
present, so an interrupted run resumes where it stopped. `python run_all.py
--force` recomputes everything. On two cores the full sequence takes roughly
three hours; the variance-based sensitivity analysis, the parameter estimation
and the population ensembles account for almost all of it.

Exact profile likelihoods are disabled by default in `tessera_experiments.e7_profiles`.
Each profile point requires a constrained re-optimisation, and away from the
optimum the system stiffens enough that one objective evaluation costs tens of
seconds. Set `enabled=True` to compute them where the budget allows; the
identifiability conclusions in the manuscript rest on the Fisher information
analysis instead, and say so.

## Verifying thermodynamic consistency

```python
import tessera_calibrate as C
th, boltz, flux, u = C.equilibrium_check()
ge, pred, spread = C.effective_potential(None, u)
print(flux)     # net cycle flux at the annulling activities
print(spread)   # path dependence of the effective potential
```

Both quantities should be at the level of floating-point round-off. The cycle
affinities are additionally invariant to any reassignment of the state free
energies, which `C.cycle_report` demonstrates by accepting a `gstate` argument.

## Determinism

Every stochastic element is seeded from `tessera_experiments.SEED`. Given the
same seeds and library versions, the pipeline reproduces the reported numbers
exactly rather than approximately.
